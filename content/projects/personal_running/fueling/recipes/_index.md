# Recipes

A growing archive of meals, snacks, drinks, and recovery options I use while training.

Each recipe should eventually include:

- Meal type
- Training use case
- Key ingredients
- Estimated cost tier
- Ingredients
- Directions
- Grocery notes
- Modifications
- Related meal plans

## Tag System

Planned recipe tags should stay consistent enough to make future filtering possible.

**Meal type:** breakfast, lunch, dinner, snack, drink

**Training use:** pre-run, post-run, recovery, long-run, race-week, everyday

**Key ingredients:** rice, pasta, orzo, oats, potatoes, beans, lentils, chicken, beef, eggs, tofu, yogurt, fruit, vegetables

**Dietary / practical:** vegetarian, vegan, halal-friendly, high-carb, high-protein, budget, moderate-cost, splurge, meal-prep, portable, low-effort
